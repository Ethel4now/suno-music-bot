# 经验教训

踩过的坑与有效做法，按主题追加，保留日期。

## Suno 前端
- 代理常导致 Create 页空白或超时；直连更稳。
- 中文歌词用剪贴板粘贴，逐字输入易乱码。
- 反复点击失败时不要循环重试，改为交接粘贴文件。

## LRC 对齐
- 原始音频解码报 `metadata_errors` 时，先转 16 kHz 单声道 WAV 再转写。
- ASR 只提供时间，不提供文本；文本以锁定歌词为准。

## 编码
- compat 必须 H.264 yuv420p / Main / `-bf 0` / AAC / `+faststart`。
- ASS 路径在 ffmpeg 滤镜里要转义 `:`。
